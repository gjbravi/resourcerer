# Optimization settings and descriptions

> Orion optimization settings, by category


This topic lists and describes the optimization settings that you can configure in Orion.

To set these values, use annotations as described in any of these topics: [Configure clusters](configure__cluster-defaults.md), [Configure namespaces](configure__annotate-namespaces.md), or [Configure workloads](configure__annotate-workloads.md).

To view settings for individual workloads in the Orion UI, click **Workloads** in the left navigation; then, click a workload name in the list and then click the **Settings** tab.
