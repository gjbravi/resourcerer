# Get started

> Get up and running with Orion


Orion collects Kubernetes observability metrics and uses machine learning to generate rightsizing recommendations for CPU and memory resource settings — helping teams reduce cloud spend and improve workload reliability without manual tuning.

## What you'll need

- A Kubernetes cluster (any distribution: EKS, AKS, GKE, minikube, kind, and others)
- A Orion account — sign up for free at **[app.orion.example/signup](https://app.orion.example/signup)**
- `helm` installed locally

In enterprise environments, verify [firewall and proxy requirements](installation__install-adv.md#prerequisites) before installing.
