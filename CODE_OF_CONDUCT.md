# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behavior to the maintainers through
[GitHub security advisories](https://github.com/gjbravi/resourcerer/security/advisories/new) or by contacting
[@gjbravi](https://github.com/gjbravi) directly.
