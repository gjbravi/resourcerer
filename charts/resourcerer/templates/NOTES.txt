WARNING: nothing here serves TLS ({{ $tls }}), so the session cookie is Secure only when a proxy in front

Parameters live in ConfigMap {{ .Release.Namespace }}/{{ include "resourcerer.fullname" . }}-auth under oidc.yaml,
which the server rereads every 30s, so a change takes effect without a restart; changing issuer or clientID signs
every session out. Change them in the chart's values, through GitOps: Helm or ArgoCD owns that ConfigMap and reverts
a kubectl edit on the next sync or self-heal.
WARNING: write access to that ConfigMap is admin access to resourcerer, because its issuer can be repointed at an
Identity Provider an attacker controls, which then issues a login resourcerer accepts as an editor. Limit who may
write ConfigMaps in this namespace.
